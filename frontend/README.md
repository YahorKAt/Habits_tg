## Frontend (React + Tailwind + Vite)

Setup:
```bash
cd frontend
npm i
npm run dev
```

Environment:
- VITE_API_URL: API base URL (default http://localhost:8000)

Telegram WebApp:
- Script `https://telegram.org/js/telegram-web-app.js` is included in `index.html`.
- App uses `X-Telegram-Init-Data` header for auth.
