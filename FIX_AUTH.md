# Исправление ошибки авторизации 401

## Проблема
Ошибка 401 Unauthorized при запросах к backend API на Render/Vercel

## Что было исправлено

### Backend (Python/FastAPI)
1. **Улучшена обработка CORS** (`backend/app/main.py`):
   - Добавлены localhost origins для разработки
   - Добавлен параметр `expose_headers=["*"]` в CORS middleware
   - Добавлена более детальная обработка ошибок с заголовками WWW-Authenticate

2. **Добавлено логирование** для отладки:
   - В `main.py` добавлены логи в функцию `get_user_id()`
   - В `telegram_auth.py` добавлены детальные логи при валидации initData
   - Логи показывают на каком этапе происходит ошибка

3. **Добавлены недостающие поля в модели** (`backend/app/models.py`):
   - Добавлено поле `mood` в модель Note
   - Добавлено поле `frequency` в модель Task

4. **Обновлен скрипт миграции** (`backend/migrate_db.py`):
   - Теперь мигрирует поля `mood` для notes и `frequency` для tasks

### Frontend (React)
1. **Улучшена обработка initData** (`frontend/src/App.jsx`):
   - Добавлена проверка на наличие initData перед отправкой заголовка
   - Используется `initDataUnsafe` как fallback для `initData`
   - Заголовок `X-Telegram-Init-Data` отправляется только если данные есть

2. **Улучшена обработка ошибок API**:
   - Все функции `api()` теперь логируют ошибки в консоль
   - Добавлены более информативные сообщения об ошибках

## Что нужно сделать для деплоя

### На Render (Backend)
1. Добавьте переменную окружения:
   - `BOT_TOKEN` - токен вашего Telegram бота

2. Установите переменную окружения (опционально):
   - `DEV_MODE` - поставьте `false` для production

3. После первого деплоя запустите миграцию БД:
   ```bash
   python backend/migrate_db.py
   ```

### На Vercel (Frontend)
1. Убедитесь, что переменная `VITE_API_URL` установлена правильно
   - Пример: `VITE_API_URL=https://habits-tg.onrender.com`

2. Убедитесь, что домен в CORS настроен правильно на backend

## Как проверить, что все работает

1. Откройте консоль браузера (F12)
2. Проверьте, что initData присутствует в заголовках запросов
3. Проверьте логи на Render - там будет видно, какая именно ошибка авторизации
4. Убедитесь, что BOT_TOKEN установлен корректно

## Возможные причины ошибки

1. **initData не передается**:
   - Приложение не запущено в Telegram
   - Проверьте логи в консоли браузера
   
2. **BOT_TOKEN не установлен или неправильный**:
   - Проверьте в Render Dashboard
   - Убедитесь, что токен правильный (получите у @BotFather)

3. **Проблемы с CORS**:
   - Убедитесь, что origin в `backend/app/main.py` соответствует вашему frontend URL
   - Проверьте логи в Render на предмет CORS ошибок

4. **База данных**:
   - Запустите миграцию: `python backend/migrate_db.py`
   - Убедитесь, что база данных создалась
