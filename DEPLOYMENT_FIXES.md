## Важно проверить на продакшене

### 1. Переменные окружения на Render (Backend)

Убедитесь, что в Render установлены:
- `BOT_TOKEN` - должен быть **одинаковый** с токеном бота
- `DATABASE_URL` - правильный URL базы данных

### 2. Переменные окружения на Vercel (Frontend)

Убедитесь, что установлен:
- `VITE_API_URL` - URL вашего бэкенда на Render (например: `https://your-app.onrender.com`)

### 3. Переменные окружения на Railway (Bot)

Убедитесь, что установлены:
- `BOT_TOKEN` - должен быть **одинаковый** с Render
- `WEBAPP_URL` - URL вашего фронтенда на Vercel

## Проверка работы

1. **Проверьте логи на Render:**
   - Запустите приложение и посмотрите логи
   - Должны видеть сообщения о валидации init_data
   - Если видите "Hash mismatch" - проверьте BOT_TOKEN

2. **Проверьте в консоли браузера:**
   - Откройте DevTools в Telegram
   - Должны видеть "Telegram initData found" в консоли
   - Проверьте что `initData` не пустой

3. **Проверьте сетевые запросы:**
   - В DevTools -> Network найдите запросы к API
   - Проверьте заголовок `X-Telegram-Init-Data` - должен присутствовать

## Возможные проблемы и решения

### Проблема: Hash не совпадает
**Решение:**
- Убедитесь что `BOT_TOKEN` одинаковый на Render и в боте
- Проверьте что токен не имеет пробелов/переносов строк
- Убедитесь что используется правильный формат: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

### Проблема: 401 Unauthorized
**Решение:**
- Проверьте логи на Render - там будет детальная информация
- Убедитесь что приложение открывается через Telegram (не в браузере)
- Проверьте что `window.Telegram.WebApp.initData` содержит данные

### Проблема: Данные не отображаются
**Решение:**
- Проверьте что запросы проходят (смотреть Network в DevTools)
- Проверьте логи бэкенда на наличие ошибок
- Убедитесь что `user_id` корректно извлекается из init_data

## Алгоритм валидации (для справки)

Согласно документации Telegram:
1. Извлекаем `hash` из init_data
2. Удаляем `hash` и `signature` из данных
3. Сортируем ключи и собираем строку `check_data = "key1=value1\nkey2=value2..."`
4. Вычисляем: `secret_key = SHA256("WebAppData" + BOT_TOKEN)`
5. Вычисляем: `computed_hash = HMAC_SHA256(secret_key, check_data)`
6. Сравниваем `computed_hash == hash`
